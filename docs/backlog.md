# Backlog

What the consuming apps have asked for and the system does not do yet, in rough priority order. Each
item lands as its own `minor` PR with stories, an axe test and a README row. Add to the bottom; strike
through when shipped.

| Item                     | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Check upstream (`@base-ui/react` Toolbar / CompositeRoot) before adding a key handler here.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `Menu` submenus          | Base UI has `Menu.SubmenuRoot` + `SubmenuTrigger`; needs the chevron, hover intent and the positioner class.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Select multiple`        | Base UI `Select` supports `multiple`; needs a value renderer for several labels and a chip-style trigger.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `Pagination`             | Page list with prev/next, current page as `aria-current`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `Avatar`                 | Image with initials fallback, `size`, `Avatar.Group`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `Dialog` nested          | Two dialogs stack by DOM order today; a nested one should dim the parent (`data-nested-dialog-open`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `DiffView`               | Unified line diff with collapsed context, today app-local in the consuming app (Files page, file proposals; about 50 lines on the `diff` package). Extract once its second use settles. Evaluate `@git-diff-view/react` (MIT, React 19, split view, word-level highlights, inline line widgets) as the engine if a consumer needs side-by-side or within-line highlights, e.g. resume version comparison. Costs to weigh: pre-1.0 (0.1.x), ~130 KB component code plus core and highlight.js, 55 hard-coded colours beyond its 23 `--diff-*` variables, its own light/dark switch. Wrap it like FileInput wraps FilePond (ADR first). |
| `PriorityNav` arrow keys | Optional in the APG disclosure navigation example (Left/Right between top-level items, Down into the panel, Home/End). Add only if the header grows submenus; Tab already covers it.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `PriorityNav` groups     | A second disclosure for a link group ("Settings" with sub-pages) in the same structure, plus a group of overflowed links inside the More panel.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Icon sizes past `xl`     | `BroomIcon` added `display` (72px). If another icon needs it, move `display` to `Icon` and the token set (`size.icon.display`) instead of a calc.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `Stepper`                | The rail and segmented progress in `FullScreenFlow` and the consuming app's application-status stepper share a shape (steps that are done, current or upcoming; `aria-current="step"`). Extract a primitive when the second use moves into the system, and rebuild `FullScreenFlow.Progress` and `Rail` on it (docs/adr/0006).                                                                                                                                                                                                                                                                                                        |
