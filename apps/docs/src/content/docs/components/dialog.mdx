A compound component: `Dialog.Root` owns the open state, `Dialog.Trigger` opens it and `Dialog.Content` is the
portal, backdrop and popup. Every part is listed under [API](#api).

```tsx
<Dialog.Root>
  <Dialog.Trigger render={<Button variant="danger" />}>Delete</Dialog.Trigger>
  <Dialog.Content size="sm">
    <Dialog.Title>Delete this application?</Dialog.Title>
    <Dialog.Description>Its notes and files go too. This can't be undone.</Dialog.Description>
    <Dialog.Actions>
      <Dialog.Close render={<Button variant="secondary" />}>Cancel</Dialog.Close>
      <Button variant="danger">Delete</Button>
    </Dialog.Actions>
  </Dialog.Content>
</Dialog.Root>
```
